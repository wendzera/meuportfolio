Modelagem de Padrões de Projetos

Professor: Jefferson Antonio Ribeiro Passerini

Introdução: A disciplina aborda a modelagem de software e o uso de padrões de projeto para criar soluções flexíveis, reutilizáveis e de fácil manutenção.

Conteúdo Abordado:

  • Princípios de projeto orientado a objetos
  • Modelagem com UML
  • Padrões criacionais
  • Padrões estruturais
  • Padrões comportamentais
  • Refatoração e boas práticas de projeto
